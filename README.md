# Leon Group LLC Website

A responsive static website for Leon Group LLC.

## Free hosting with your existing domain

GitHub Pages can host this site for free with a GitHub Free account and supports custom domains.

1. Create a public GitHub repository (for example: `leon-group-website`).
2. Upload `index.html` and `CNAME`.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, and save.
5. Under **Custom domain**, enter `www.leongroupllc.com`.
6. At the company/domain registrar where `leongroupllc.com` is managed, create a DNS CNAME record:
   - Name/Host: `www`
   - Target/Value: your GitHub Pages address, such as `YOURUSERNAME.github.io`
7. Turn on HTTPS after GitHub makes it available.

The exact DNS screen varies by your domain provider.
